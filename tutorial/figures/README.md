# Tutorial figure policy

Place course-wide source figures in `common/` and session-specific source
figures in `01/` through `06/`. Prefer PDF for vector artwork and use PNG or
JPEG only for inherently raster material.

For every added figure, record its creator, source, license, and any adaptation
in this file or in an adjacent text file. Do not store plots, tables, solver
results, screenshots of notebook output, or other generated exercise results
here; those belong in the ignored `tutorial/outputs/` tree.
