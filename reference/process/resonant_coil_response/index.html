Overview

On a fixed equilibrium, toroidal mode n and plasma-response model, the complex resonant flux GPEC writes at the rational surfaces (Phi_res total, Phi_res_v vacuum; area-normalized, tesla) responds linearly to the coil excitation. This module holds that operator, built from per-group unit runs and verified on held-out runs rather than assumed, and the optimizations issue #1884 asks of it (issue #1178 umbrella). It runs no solver.

The response is linear in conj(c). VAFT’s excitation (vaft.process.coil_operating_space.COIL_EXCITATION_CONVENTION) is I_k = A cos(n phi_k + delta) = Re(c exp(+i n phi_k)); GPEC decomposes in exp(-i n phi), whose coefficient is conj(c) / 2. Measured on the DIII-D-like example (#1884): Phi(i e_k) = -i Phi(e_k) exactly, and Phi = H conj(c) reproduces every held-out run to 4e-6. Hence Q = conj(H^H W H) for a quadratic metric in c; using H^H W H instead would mirror every optimal relative phase.

Squared, not RMS, is optimized. J with window_weights is the window’s mean squared magnitude; its square root is vaft.process.perturbation.rms_resonant_field for the same surfaces, so the ordering is the same for a fixed non-empty window. Results report which one they hold.

Total and vacuum stay apart. Phi_res and Phi_res_v get separate operators; nothing here subtracts them.

Processing steps · Applicability · Limitations · Provenance

Processing steps

  1. infeasible when even the least c^H Q_c c on the budget (the bottom generalized eigenvector of (Q_c, D)) exceeds the cap.
  2. For a multiplier mu, the top generalized eigenspace of (Q_o - mu Q_c, D); mu = 0 if some excitation in it meets the cap.
  3. Otherwise bisect mu on the least constraint within that space, and at the converged mu combine the space’s extreme directions so the constraint lands on the cap (the objective is then maximal).

Applicability

Machine-independent.

Limitations

The multiplier route is exact for two Hermitian quadratic forms on a complex sphere (no duality gap); degenerate top eigenvalues, which occur whenever the cap’s null space lies inside the objective’s (e.g. more groups than capped surfaces), are handled by working on the eigenspace. Eigenvalues within 1e-9 of the spectral scale are treated as equal. Sector-current limits are not imposed.

Provenance

  1. Issue #1884, Sec. 4 stage D.

Convention

The target is complex: its phase is physical here, so no group’s phase is fixed. With lambda = 0 and a rank-deficient W^1/2 H the returned c is the minimum-norm one, and the null space says what else fits.

Raises

  • ValueError Shapes disagree, W or D is not Hermitian, D is not positive definite, or regularization is negative.
Processing steps · Applicability · Limitations · Provenance

Processing steps

  1. With g = conj(c): minimize ||W^1/2 (H g - t)||^2 + lambda g^H conj(D) g.
  2. Solve the stacked system [W^1/2 H; sqrt(lambda) L^H] g = [W^1/2 t; 0] (conj(D) = L L^H) by least squares, never by an explicit inverse.
  3. c = conj(g); report the SVD of W^1/2 H and its null space.

Applicability

Machine-independent.

Limitations

A phasor-space answer: actual sector currents, winding signs and circuit limits must be checked separately. A zero target with lambda > 0 returns c = 0; ask for a nontrivial target instead.

Provenance

  1. Issue #1884, Sec. 4 stage B.
