# VAFT brand typeface

`IBMPlexSansCondensed-SemiBold.ttf` is IBM Plex Sans Condensed SemiBold, supplied
under the SIL Open Font License 1.1 in `OFL.txt`.

Source: [Google Fonts, IBM Plex Sans Condensed](https://github.com/google/fonts/tree/main/ofl/ibmplexsanscondensed).
The font file is used to outline the VAFT wordmark and social preview in
`../make_brand_assets.py`; the documentation hero uses the same local font.
Regenerating the brand assets requires `fonttools` in addition to the generator's
other dependencies.
