Overview

Formula and process docstrings declare every unit as a [unit] tag, and the callers of a function that takes I_p [MA] or n [1e19 m^-3] convert by hand. This module turns such a tag into a scale factor and a dimension, so a conversion can be checked and stated instead of retyped (#2163).

It converts only what a unit tag can decide on its own. Two values with convertible units are not thereby the same physical quantity: whether a line-averaged and a separatrix density may be compared is a question of quantity identity, answered by vaft.data.representation, never here.

SymbolMeaningUnit
sscale of a unit in SI base units-
dbase-dimension exponents (L, M, T, I), as in vaft.formula.dimensional [-]
kexponent of the plane angle-

Only the symbols in the table are known. An unknown symbol raises; no prefix is inferred, so ms is a millisecond only because it is listed.

Angles are tracked, not erased. The radian is dimensionless in SI, but a flux in Wb and a flux in Wb/rad are two COCOS conventions, not one quantity in two units: the factor between them is $2\pi$ only together with the sign changes of the COCOS transform (Sauter and Medvedev 2013). The plane angle therefore keeps its own exponent $k$, and two units whose $k$ differ never convert.

Percent is a scale. % is the dimensionless unit with scale 0.01, so a beta fraction and the same beta in percent convert. Normalized beta, % m T/MA, is a different quantity with a different dimension.

parse_unit

Convention-sensitive source 
parse_unit(unit)
Show source vaft/formula/units.py, lines 147–209

Parse a [unit] tag into its scale, dimension and angle exponent.

\[u = f \prod_j s_j^{p_j},\qquad d(u) = \sum_j p_j\, d(s_j)\]

A tag is an optional positive leading numeric factor f followed by symbols s_j with optional integer powers ^p_j, separated by spaces. A / divides every symbol after it, so % m T/MA is percent times metre times tesla per megaampere.

NameTypeUnitDescription
unitstr-

The tag without its brackets, e.g. "MA", "1e19 m^-3".
Returns
—UnitSpec-

Scale in SI, (L, M, T, I) exponents and the plane-angle exponent.

Convention

No SI prefix is inferred: ms is the millisecond because the table lists it, and Mm is unknown. - and % are dimensionless with scales 1 and 0.01. rad and deg carry a plane-angle exponent of one, so Wb/rad keeps an angle exponent of -1 that Wb does not have.

Raises

  • UnknownUnitError The tag is empty, malformed, or uses a symbol not in the table.

Factor that turns a value in source units into target units.

\[x_{\mathrm{target}} = \frac{s_{\mathrm{source}}}{s_{\mathrm{target}}}\, x_{\mathrm{source}}\]
NameTypeUnitDescription
sourcestr-

Unit tag of the value as held, e.g. "A".

targetstr-

Unit tag the value is wanted in, e.g. "MA".
Returns
—float-

The multiplicative factor, 1e-6 for A to MA.

Convention

Only scale is converted. A unit change that a convention decides, such as poloidal flux in Wb against Wb/rad (COCOS 11-18 against 1-8), is refused with a pointer to vaft.process.equilibrium.convert_cocos, because the factor $2\pi$ alone would leave the signs of the other convention.

Raises

  • UnknownUnitError Either tag cannot be parsed.
  • IncompatibleUnitsError The units differ in base dimension, or in plane-angle exponent.
