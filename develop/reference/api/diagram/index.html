Modules without a declared public surface

These modules declare no __all__, so this reference cannot tell what they publish and lists nothing from them (docs/api_inventory.yml). Some are reached through a package that re-exports and declares them – vaft.omas publishes the functions of the wrapper modules it star-imports, under vaft.omas above – and the rest are described in the hand-written guides until they declare one: vaft.diagram.build.
