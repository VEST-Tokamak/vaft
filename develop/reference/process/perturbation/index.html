Overview

A 3-D perturbation is felt at the surfaces where it resonates, and a code like GPEC reports one row per rational surface: the resonant flux, the shielding current, the island it would open, the Chirikov parameter. Reading those rows is vaft.code.gpec’s job and it is done; this module is what turns a table of them into the few numbers a study actually compares.

Nothing here is specific to a machine or to a code. The input is a radial coordinate and a column of values; resonant_metrics takes the mapping vaft.code.gpec.GpecProfileOutput.resonant_table returns because that is the shape the data already has, not because the module knows about GPEC.

Two things this module is careful about, because the code it replaces was not.

Where a region starts and ends is not a constant. The legacy metrics hard-code the core at psi_n <= 0.8 and the edge at 0.8 to 0.95, and seven different window sets are scattered across the notebooks that used them (convention C-16). Decision D-05 settles it: the boundary comes from the pedestal, through vaft.process.profile.pedestal_top, and every reduction records which window it used and where that window came from. The legacy numbers survive only as LEGACY_WINDOWS, so an old result can still be reproduced deliberately.

A reduction is not a verdict. vaft.process computes; it does not decide. The thresholds the legacy compared against – a Chirikov parameter of 1, a penetration ratio of 1, an edge overlap of 7.4e-4 – are arguments here and defaults nowhere, and nothing in this module returns “stable”. A study that wants a verdict registers one in vaft.validation.

Units are SI throughout: the resonant flux is in tesla, as GPEC writes it, and is not multiplied by 1e4. The legacy reported gauss, silently, inside the reduction; a factor of ten thousand belongs to a display layer that says which unit it is showing.

amplification_ratio

amplification_ratio(psi_norm, values, reference_psi_norm, reference_values, *, window, statistic='rms')

Machine-independent.

How much larger one run’s resonant response is than another’s.

ParameterTypeUnitDescription
psi_normarray_like-

Rational-surface coordinate of the case.

valuesarray_likeany

The case’s resonant column.

reference_psi_normarray_like-

Rational-surface coordinate of the reference, usually the vacuum run

reference_valuesarray_likeany

The reference’s resonant column, in the same unit as values.

windowResonantWindow-

The interval both are reduced over.

statisticstr, optionaln/a

One of RESONANT_STATISTICS.
ReturnsTypeUnitDescription
float-

Case over reference; nan when either window is empty or the reference reduces to zero.

Processing steps.

  1. Reduce each run over window independently, so the two need not share a rational-surface set.
  2. Divide.

Applicability.

Machine-independent.

Limitations.

Both runs are reduced on their own surfaces. Two equilibria resonate at different places, and interpolating one onto the other’s surfaces would invent a resonance where there is none.

Provenance.

  1. gpec_analysis.calculate_amplification_ratio, which fell back to the vacuum column silently when the plasma one was absent – returning a ratio of one and calling it no amplification. Not carried over: an absent column raises here.

reduce_resonant

reduce_resonant(psi_norm, values, *, window, statistic='rms')

Machine-independent. Convention-sensitive.

Reduce one resonant column over one radial window.

Complex columns – the resonant flux, the shielding current, the resonance parameter – are reduced on their magnitude: a complex mean depends on a gauge the file does not fix, so averaging the phase would give an answer that changes with a convention rather than with the plasma. A real column keeps its sign, so mean of a rotation profile that changes sign is that mean and not its rectification; pass numpy.abs(values) to reduce a signed column on magnitude.

ParameterTypeUnitDescription
psi_normarray_like-

Normalized poloidal flux of each rational surface.

valuesarray_likeany

One column of the resonant table, real or complex.

windowResonantWindow-

The interval to reduce over.

statisticstr, optionaln/a

One of RESONANT_STATISTICS.
ReturnsTypeUnitDescription
floatany

The reduced value, in the column’s own unit; nan when the window holds no surface.

Raises.

ValueError psi_norm and values differ in length, or statistic is not one of RESONANT_STATISTICS.

Processing steps.

  1. Take the magnitude of a complex column; leave a real one signed.
  2. Select the surfaces inside window.
  3. Drop non-finite samples, then apply statistic.

Convention.

A complex column reduces on its magnitude and a real one keeps its sign; the value comes back in the column’s own unit, unscaled.

Applicability.

Machine-independent. Any per-rational-surface column.

Limitations.

Returns nan rather than raising when the window is empty: a plasma with no rational surface in a region is a normal result, and a run with four rational surfaces has regions that are legitimately empty.

Provenance.

  1. Conventions register C-18: quantities on the rational-surface index must not be averaged with quantities on the mode index, and a complex mean is gauge-dependent.

resonant_metrics

resonant_metrics(table, *, windows, columns=None, statistic='rms')

Machine-independent. Convention-sensitive.

Reduce every named column of a resonant table over every window.

ParameterTypeUnitDescription
tablemapping of str to ndarrayany

A resonant table, as vaft.code.gpec.GpecProfileOutput.resonant_table returns it; it must carry psi_n_rational.

windowsmapping of str to ResonantWindow-

The windows to reduce over, from resonant_windows.

columnssequence of str, optionaln/a

Which columns to reduce; those of RESONANT_RESPONSE_COLUMNS the table carries, by default. Anything else – a coordinate, or an equilibrium profile sampled at the surfaces – has to be named, so that reducing it is a decision rather than a side effect.

statisticstr, optionaln/a

One of RESONANT_STATISTICS.
ReturnsTypeUnitDescription
dictany

Keyed (column, window), in the column’s own unit.

Raises.

KeyError The table carries no psi_n_rational, no response column at all, or not one that columns named.

Convention.

Inherits reduce_resonant’s – magnitudes for complex columns, the column’s own unit – and the window convention of whatever resonant_windows produced.

Applicability.

Machine-independent.

Limitations.

A reconstruction run carries rational surfaces and no perturbed response, and a kinetic run may carry no rational-surface block at all – its table comes back empty. Both are refused here rather than reduced into something that looks like an answer.

Provenance.

  1. gpec_analysis_metrics.compute_metric_table, which carried the same reductions with the windows and the gauss factor built in.

resonant_windows

resonant_windows(pedestal=None, *, legacy=False)

Machine-independent. Convention-sensitive.

The core, edge and total radial windows a reduction is taken over.

The core/edge boundary comes from the pedestal rather than from a constant. With a PedestalTop that resolved a fit, the edge begins at the pedestal’s inner knee; with one that fell back, it begins at the fallback position, and the window says so.

ParameterTypeUnitDescription
pedestalPedestalTop, optional-

The pedestal boundary, from vaft.process.profile.pedestal_top. Omit it only together with legacy=True.

legacybool, optional-

Return LEGACY_WINDOWS instead, for reproducing a published number that used them.
ReturnsTypeUnitDescription
dict of str to ResonantWindow-

Keyed core, edge, total, each carrying its own bounds and the source they were derived from.

Raises.

ValueError Neither a pedestal nor legacy=True was given, or the pedestal’s coordinate is not psi_norm.

Defaults.

The 0.8 and 0.95 boundaries of LEGACY_WINDOWS are a legacy compatibility value, not a physical one: they are what the metrics this module replaces hard-coded.

Convention.

Bounds are normalized poloidal flux, endpoints included at both ends, so a rational surface exactly at the boundary is counted in both neighbours rather than dropped by one.

Applicability.

Machine-independent. Any radial coordinate expressed as normalized poloidal flux.

Provenance.

  1. Migration decision D-05: the pedestal top is determined from an EPED-style profile fit, and core, edge and pedestal regions are derived from that result rather than fixed.
  2. Conventions register C-16: seven different core/edge/pedestal window sets were in use across the code this replaces.

Resonant flux per surface, complex as GPEC writes it.

windowResonantWindow-

The interval to reduce over.
ReturnsTypeUnitDescription
floatT

RMS magnitude, in tesla; nan when the window holds no surface.

Convention.

Tesla, not gauss. GPEC normalizes this flux by the surface area, so it carries field units already; the code this replaces multiplied by 1e4 inside the reduction, which put a unit conversion where nothing said so.

Provenance.
