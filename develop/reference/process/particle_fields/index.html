Overview

All factories return static Cartesian SI-valued ParticleField objects. Analytic examples are controlled reference geometries, not reconstructed VEST equilibria.

Processing steps · Applicability · Limitations · Provenance

Processing steps

Reuse the equilibrium interpolator and its COCOS sign/flux handling. Convert its (B_R,B_Z,B_phi) components to Cartesian order and enforce map bounds.

Applicability

Machine-independent. A resolved static equilibrium snapshot.

Limitations

The underlying interpolator clips F beyond the profile range; this adapter does not validate the equilibrium or invent a vector-potential gauge.

Provenance

  1. vaft.process.equilibrium.make_equilibrium_field_interpolator.

Processing steps · Applicability · Limitations · Provenance

Processing steps

Reuse the existing midpoint-rule Biot-Savart field. Evaluate A with the same midpoint quadrature, so curl(A) is exactly the represented B.

Applicability

Machine-independent. Closed vacuum filaments away from conductor singularities.

Limitations

No finite conductor radius, plasma response or wall currents are modeled.

Provenance

  1. vaft.process.coils_non_axisymmetric.biot_savart_filaments.

Construct an exactly solenoidal axisymmetric parabolic mirror field.

NameTypeUnitDescription
B0float, optionalT

Minimum on-axis field, a benchmark default.

lengthfloat, optionalm

Half length of the accepted mirror domain, a benchmark default.
Returns
—ParticleField-

Field with Bz = B0(1+z^2/length^2) and Br = -r B0 z/length^2.

Convention

The domain is abs(z) < length and r < length/4. On axis, s=z and the nominal mirror ratio at the two ends is two. This is a current-carrying analytic benchmark, not an assertion of a vacuum-coil solution.

Applicability · Provenance

Applicability

Machine-independent. Magnetized mirror and harmonic-bounce benchmark.

Provenance

  1. Curl of A=(-y f(z)/2, x f(z)/2, 0), f=B0(1+z^2/L^2), an exactly divergence-free benchmark for issue #2005.

Construct an axisymmetric torus with an optional curl-defined 3-D perturbation.

Step retained for independent derivative audits; the benchmark supplies an analytic Jacobian. This is a numerical convenience.

constant_magnitudebool, optional-

Use Bphi=B0 with poloidal=perturbation=0 for a local pure-curvature benchmark; default False uses the vacuum F/R component.
Returns
—ParticleField-

Curl-defined field, vector potential and explicit toroidal domain.

Convention

phi=atan2(y,x), e_phi=(-sin(phi),cos(phi),0). The physical flux per radian is R A_phi; no COCOS label is inferred for this Cartesian benchmark. A_z=-B0 R0 log(R/R0)+a B0 R0 (R/R0)^n cos(n phi)/n. The perturbation represents a controlled vacuum transverse harmonic, not a plasma response.

Applicability · Limitations · Provenance

Applicability

Machine-independent. Axisymmetric orbit and static symmetry-breaking tests.

Limitations

The circular current-carrying poloidal field is not a Grad-Shafranov solve. Use reconstructed equilibria for machine-specific orbit claims.

Provenance

  1. Analytic curl of the stated vector potential, issues #2008/#2009.
