# VAFT documentation, published

This branch is **generated output**. Every file here is written by
`docs/build.py` and replaced wholesale on each publish, so an edit made
here survives exactly until the next one and reaches nobody's review.

The source lives in `docs/` on the code branches: the site root is built
from `main`, and `/develop/` is built from `develop`. `provenance.yml`
records which commit each half came from.

To change the documentation, change `docs/` on the branch it belongs to.
